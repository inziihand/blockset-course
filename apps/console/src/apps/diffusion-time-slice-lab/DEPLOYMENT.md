# 熱擴散到華爾街 App 部署規格

狀態：純前端離線互動教學 App；目前為本機實作，尚未部署至正式環境。

## App 責任

- 使用瀏覽器端 TypeScript 計算高斯機率密度、期間標準差與時間切片。
- 以單一流程滑桿連續控制正面、傾斜、7 張切片依序增加、曲面與俯視投影，並保留時間方向、一個標準差與波動率控制。
- 啟動時依波動率與時間建立唯一的連續曲面資料；可見時間切片是從該曲面的時間網格分段取列，±1σ 連線也直接從同一曲面取樣。
- 教學曲面固定取樣 30–180 天，避開 `t → 0` 的極尖分布；不另外提供重複語意的總時間控制。
- 30–180 天資料會重新映射至完整時間軸，不保留 0–30 天的空白區段；反轉後同樣填滿整條剩餘時間軸。
- 傾斜視角加入輕微透視：最近切片維持 100%，最遠切片的報酬寬度與密度高度縮至 90%；正面與俯視維持正交，切換時連續插值。
- 彩色曲面依正規化密度套用 viridis 式色階：低值為紫色、中值為藍綠色、高值為黃綠色。
- 可見切片總數固定為 7，不提供切片數量控制；流程滑桿只負責由 1 張逐步揭示至 7 張。
- App 標題列提供區塊對調控制；桌面交換左右欄，窄畫面交換上下順序，並以 FLIP 動畫平滑移動。
- 報酬座標使用固定顯示範圍，不跟著當前標準差重新縮放，因此調整時間或波動率會實際改變畫面中的分布寬度。
- 曲面使用 33 個時間樣本，每張分布曲線使用 181 個報酬資料點，以降低折線感。
- 流程滑桿與圖層開關只控制曲面、切片及標準差連線的投影與顯示，不建立另一份切片資料；可見切片上限為 1 時完整曲面仍然存在。
- 不讀取市場行情、會員交易資料或券商帳戶，不提供下單、改單或撤單能力。

## Health、驗收與回滾

- Registry 與路由可載入 App。
- 三個視角階段共用唯一曲面資料與可插值投影；擴散時間從第一片往後揭示，剩餘時間從最後一片往前揭示，切片前後對調不重算曲面。
- 可見時間切片必須是曲面網格中的實際列，標準差連線的每一點必須對應同一列曲面的 `±σ` 位置。
- 每個正時間切片的密度數值積分接近 1，期間標準差符合 `σ√τ`。
- 控制元件可用鍵盤操作，窄畫面不產生水平溢位。
- `npm run check:apps`、`npm run check:services`、`npm run check:boundaries`、`npm test` 與 `npm run build` 通過。
- 純前端回滾隨 Hosting release 或 App source-install transaction；沒有資料 migration。
