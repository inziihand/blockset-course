# 驗收矩陣

狀態：以下為 P1～P8 待實作案例，尚無已執行測試。

Python 單元／Adapter contract tests 放 `backend/tests`；前端元件測試放 `apps/console`；此目錄預留跨元件情境、回放 fixtures 與 E2E。

| 類別 | 核心案例 |
| --- | --- |
| 單位 | TX／MTX／TMF 乘數、整數口、TWD 金額、無效精度與未知欄位 |
| 時間 | 日夜盤、午夜、週末、連假、特殊休市、到期提早收盤、ROD 到盤 |
| 委託 | 回報早於返回、亂序／重複、部分成交、取消與成交競爭、改單拒絕 |
| 未知寫入 | 送達後逾時、無單號、查詢歷史不完整、重啟前後同 intent |
| 復原 | SDK 斷線／重連、callback 缺口、磁碟失敗、程序崩潰、雙 Worker |
| 歸屬 | 舊 run 復原、外部手動增減量、同方向但未知來源、錯帳戶回報 |
| 控制通道 | 斷線續跑、過期命令、舊 revision、重送命令、停止覆蓋排隊啟動 |
| 前端 | 手機／桌面同帳戶一致、切帳戶競爭、過期快照、階段與燈號一致 |
| 正式差異 | 權限／CA、查詢範圍、平倉保障、成本／稅／保證金與真實對帳 |

Fake Broker、券商模擬與正式環境分開標記；故障注入只在明確安排的測試環境執行。前端固定快照不得冒充真實 Worker。
