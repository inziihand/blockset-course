# 前端平台 Codex 任務清單

更新：2026-09-16。目標：讓新 App 只需處理業務內容，共用平台的導覽、介面與基本服務。

目前第一、二批完成；第三批程式及 Chrome 驗收完成，WebKit 下載受阻待補驗收；第四批已有可選 Firebase Google 登入基礎，但後端授權與帳戶／Worker 整合仍待完成。每批證據見 [平台實施紀錄](evidence/FRONTEND-platform-20260916.md)。

## 第一批：App 承載能力

- [x] F1 網址導覽：固定 App 路徑、重新整理、上一頁／下一頁、直接連結、找不到頁面；網址作為目前頁面的來源，不再另存一份 activeApp。
- [x] F2 統一容器與接入規則：平台固定提供導覽、標題與內容區；Registry 定義唯一 ID／路徑、元件與狀態，檢查重複值；App 不重做 Shell，離開時清理請求／訂閱。
- [x] F3 載入與錯誤隔離：App 按需載入、載入中畫面、渲染錯誤邊界、載入失敗提示與返回首頁；某個 App 出錯仍可使用平台導覽。

驗收：用測試元件證明 App 切換、網址復原、未知路徑與故障返回都可用。

## 第二批：共用介面與資料服務

- [x] F4 最小共用元件：按鈕、欄位、確認視窗、通知、載入／空資料／錯誤狀態；沿用既有主題，支援手機與鍵盤。設定按平台／App 分區，先只保存已存在的偏好，不預建大型設定系統。
- [x] F5 共用 API 請求：可設定 API 位址、取消／逾時、統一錯誤與請求識別；只對明確安全的讀取做有限重試，交易命令結果不明不得自動重送。先用離線替身驗證，正式業務型別待後端 OpenAPI 產生。

驗收：不同測試元件共用相同服務；切換後舊請求不污染新畫面，失敗不造成整頁空白。

## 第三批：平台驗收與交付

- [ ] F6 建立兩個只存在測試宿主的 App，涵蓋正常、延遲與故意拋錯，與一般 Registry 隔離。補路由／切換／故障復原的瀏覽器測試、CI 測試建置、版本辨識與簡短 App 接入說明；記錄桌面／手機及目標瀏覽器結果。

進度：兩個離線 App、瀏覽器測試、CI workflow、版本及 [接入契約](FRONTEND_APP_GUIDE.md) 已建立。本次含 F9／F10 與整窗窄版修正的回歸：單元／整合 154／154、Chrome 桌面／手機 24／24 通過；WebKit 套件下載逾時，未實測，因此 F6 暫不勾選。尚未推送或執行雲端 CI。

驗收：新增測試 App 不需修改 Shell 業務判斷；一個 App 失敗不妨礙另一個。完成前三批可稱為「可承載 App 的前端平台」，不宣稱已有登入或交易能力。

## 第四批：後端就緒後整合

- [ ] F7 身分與權限：Firebase Auth SDK、可選設定、Google 登入、登出與 ID Token 介面已建立；仍需可信任後端驗證 token、處理過期／撤銷、設定 custom claim、實作功能與帳戶權限。前端只負責呈現，不以信箱比對或隱藏選單代替安全檢查。
- [ ] F8 帳戶與執行狀態：共用帳戶／環境範圍、切換清理、舊回應丟棄及資料過期提示；交易 App 的燈號／階段／按鈕共用 Worker 快照與 selector，不各自推測策略狀態。

依賴：後端 API／身分方案與共用契約就緒，配合主計畫 P1／P5。驗收包含無權限拒絕、登入過期、跨帳戶不混資料、舊快照不顯示正常。

## 本次追加：App 接入契約與 Demo

本次使用者已授權在一般 App 清單新增 Demo；原有故障注入 fixtures 仍只供測試宿主使用。F7／F8 的後端整合前置條件不變。

2026-09-16 規格修正：compact 改為整個 `main.app-shell` 一起縮窄（含 StratExec 頂列、App 標題、內容及頁尾），最大 420 CSS px 含邊框／內距，小螢幕依可用寬度縮小。外部側欄／選單及瀏覽器視窗不變；原「只縮內容」的實作已調整，先前驗收紀錄保留為歷史結果，新的尺寸驗收見 [整個 App 視窗窄版修正](evidence/FRONTEND-compact-window-20260916.md)。

證據：[App 契約與 Demo 驗收](evidence/FRONTEND-app-contract-demo-20260916.md)。本機一般平台已可開啟，沒有部署或連接券商。

## 執行規則

- 後續可直接說「執行前端平台第一批」，避免與舊 DeriStrat 批次混淆。
- 每批完成跑 `npm test`、`npm run build` 與該批必要的瀏覽器檢查；更新本清單並附簡短驗證紀錄，未實測不勾選。
- 保持單一 React 專案、靜態 Registry；不做微前端、外掛商城或各 App 獨立部署。
- 不新增正式業務 App、不複製舊服務憑證、不改舊專案；部署、券商連線及交易另依當次授權。
- 切 App、關網頁、前端出錯都不是停止策略命令；執行權與實際策略狀態仍由後端負責。
- 本清單是前端子任務的進度來源；[主實施清單](IMPLEMENTATION_PLAN.md) 仍管理 P0～P9，完成此處不等於整個 P1／P5 完成。
